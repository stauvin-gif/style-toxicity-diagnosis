# Style Toxicity Diagnosis (STD)

Static beta website. No build step required.

## Test locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, e.g. `style-toxicity-diagnosis`.
2. Upload every file in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then **Save**.
6. GitHub will provide the public Pages URL after deployment completes.

The site uses only relative asset paths, so it is ready for GitHub Pages as-is.
